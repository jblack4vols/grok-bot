# grok-bot

Durable knowledge log for Jordan Black's Grok Bots. Chat memory dies when the thread ends. This repo is the searchable, versioned record.

## Layout

One folder per bot (kebab-case of the display name). One file per day, dated America/New_York:

`knowledge-log/2026-08-25.md`

## What belongs here

Decisions, shipped work, and standing preferences.

## What does not

Secrets, tokens, passwords, customer data, private messages. No file if a bot had a blank day.

## Cadence

Knowledge Log writes at 5:50am America/New_York. Quiet if nothing to add.
