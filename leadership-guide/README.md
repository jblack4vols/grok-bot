# Grok Bots Leadership Playbook

Internal guide for TriStar PT leadership on how to use the Grok Bot fleet.

## Open locally

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Then visit `http://127.0.0.1:8765`.

## What it covers

- Operating model: bots draft / flag / brief; leaders approve
- Weekday morning cadence (America/New_York)
- Role starters for Owner, Finance/RCM, Ops/Clinical, Marketing
- Searchable bot catalog from the live knowledge-log fleet
- Standing principles and anti-patterns

Source of truth for bot decisions remains the dated knowledge logs in this repo.
